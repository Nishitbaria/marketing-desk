Room block ka exact change dekho 
# params
bridge:
  type: bridge
  description: The chat app this room lives in.
  required: false      # empty means the server's default app
directory:
  type: directory
  input: ask           # no default path

room:
  name: studio-studio
  bridge: "{bridge}"
  agents: [studio-director, studio-quill, studio-cut, studio-keeper]
  users: ["{$creator}"]
  instructions: |
    Post in English. The creator talks to @studio-director.
    An @name wakes that agent, so use one only for a real handoff.
    Before you start, use read_context to find the latest work.
    If a step fails, post the exact error. Never claim unfinished work.
    Only the creator approves. Agents never publish.

04 / TUMHARE DECISIONS

Yeh sirf tum decide kar sakte ho

1. MP4 chat me bhejein?

Recommendation: haan, sirf is private room me. send_attachment tool exist karta hai, 20MB limit ke saath. Abhi template aur repo rule "never upload" bolte hain, to rule ko "never publish outside the room" karna padega.

2. Kaun sa chat app?

Recommendation: Slack ya Discord, jo already set ho. Maine tumhare server ke bridges nahi dekhe. Setup 17:00 tak na ho to default app use karo.
