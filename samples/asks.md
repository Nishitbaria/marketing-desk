# Sample asks

DEMO / SYNTHETIC. Paste one into the `studio-studio` room. Driftnote is the fictional product in `brand/brand-kit.md`.

## 1. Launch video with a missing fact

```
@studio-director 30s launch video for Driftnote Plus, and mention the price
```

## 2. Explainer

```
@studio-director explainer for Driftnote: how the weekly recap works, for people who have never journaled. Keep it under 90 seconds.
```

## 3. Faceless short

```
@studio-director faceless short for TikTok and Reels. Hook on "you don't need a new habit". No faces, just the phone and text.
```

## 4. New brand from a website

```
@studio-director brand intake https://your-site.com
```

## Passing

Ask 1 passes when the script holds `[need: price]`, Cut does not start, and Director asks you for the price. Driftnote Plus has no price in the brand files, so no agent may state one until you give it. Tag `@studio-director` in every reply.

Ask 4 passes when Keeper posts a draft with 3 voice options, writes no file until you pick, and every fact is on the site. It replaces the demo brand, so run `git checkout brand/` to go back to Driftnote.
