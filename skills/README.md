# Skills

Each agent reads its own folder. `formats/` holds the video types Brief plans with.

| Folder | Agent | Skills |
|---|---|---|
| `quill/` | Quill, script writer | hooks, script-writer, formats. The only folder the current template uses; see `quill/SOURCES.md` |
| `brief/` | Brief, producer | script-writer, youtube-hook-plot, trend-picker, product-analyzer, content-analyzer |
| `reel/` | Reel, talent | ugc-flow, ugc-product-flow, ugc-saas-flow, ugc-tutorial-flow, ugc-unboxing-flow, ad-copy, ai-influencer-flow |
| `cut/` | Cut, editor | montage, edit, video-repurpose, thumbnail-generation, audio-generation |
| `keeper/` | Keeper, brand manager | brand-analyzer, brandkit, design-md |
| `formats/` | Brief (reference) | product-reel, video-explainer-workflow, youtube-faceless-video, tv-ad |

Copied from [Nishitbaria/super-creator](https://github.com/Nishitbaria/super-creator) by the same author, unchanged except that bundled font files were left out. The `design-md` skill describes Google's [DESIGN.md](https://github.com/google-labs-code/design.md) format, which is Apache-2.0.
