# Script writer

How Quill turns one line into a timed script. The reply format lives in Quill's instructions; this file is the craft.

## Before writing

1. Pick the video type from the ask: launch, explainer, ugc or faceless. See `formats.md`.
2. Find the one thing the viewer should remember. If the ask makes it unclear, infer it and state the assumption in Open questions.
3. List the real material: what the creator said and the brand kit facts for this product. Everything in the script comes from that list.

## Fit the words to the time

- Use the brand kit's voiceover pace. With no pace given, use 150 words a minute.
- Budget each beat before writing it: seconds × words a minute ÷ 60. At 140 words a minute, a 30 second video holds about 70 spoken words.
- Count the words in each beat. Cut a line rather than speed up the read.
- Beats must cover the full length with no gaps or overlaps, and the last beat must end at the stated length.

## Default beats

| Length | Beats |
|---|---|
| 15s | 0–3s HOOK, 3–11s SOLUTION/DEMO, 11–15s CTA |
| 30s | 0–3s HOOK, 3–10s PROBLEM, 10–22s SOLUTION/DEMO, 22–30s CTA |
| 60s | 0–3s HOOK, 3–15s PROBLEM, 15–45s SOLUTION/DEMO, 45–60s CTA |
| 90s | 0–3s HOOK, 3–20s PROBLEM, 20–50s HOW IT WORKS, 50–75s EXAMPLE, 75–90s CTA |

Other lengths scale from the nearest row, keeping the hook at 3 seconds.

## Writing a beat

- Label each line Spoken or On-screen so the editor knows which it is.
- The line after the hook delivers on it. Never open with a promise the script drops.
- One idea per beat.
- Write for the ear. Read it aloud; if you stumble, rewrite it.
- The script opens with the first hook option unless the creator picks another.
- The CTA asks for one action. If the link is missing, write [need: CTA link] and list it in Open questions.

## Shot list

One line per beat, in the same order, saying what the viewer sees: subject, setting, on-screen text. Describe the frame. Do not write camera prompts, model names or style keywords.

## Check before posting

- Six parts, in order, and the required last line.
- Every hook is under 12 words. Count them.
- Beat timestamps add up to the stated length.
- Every claim traces to the creator's message or the brand kit's facts.
- No banned word appears anywhere.
