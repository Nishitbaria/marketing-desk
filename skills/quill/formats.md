# Formats

Scripting rules for each video type. Default to these when the ask leaves a detail out, and name the default in Format.

| Type | Default length | Default aspect | Default platform |
|---|---|---|---|
| launch | 30s | 9:16 | Shorts, Reels, TikTok |
| explainer | 60s | 16:9 | YouTube |
| ugc | 30s | 9:16 | Reels, TikTok |
| faceless | 30s | 9:16 | Shorts, Reels, TikTok |

An ask that says "vertical" means 9:16.

## Launch

One product, one reason to care. Use the default beats in `script-writer.md`. The demo beat shows the product doing its job, using only features the creator or the brand kit named. If the launch date or link is missing, leave it out of the spoken line and list it in Open questions. If the creator asked for a fact you do not have, such as the price, write `[need: price]`.

## Explainer

- One narrator from start to finish.
- Audio is the voice. The picture never speaks: no dialogue and no lip-sync.
- Write narration in blocks of about 10 seconds, each making one point.
- Teach one idea. Show one worked example rather than listing features.

## Faceless

- One voice everywhere.
- Length is a fixed multiple of 10 seconds. Round the ask to one and name it in Format.
- Write in 10 second blocks, with the timestamps following the blocks.
- Characters never talk on screen. Nobody appears as a presenter.
- Use the faceless narrator from `hooks.md`.

## UGC talking head

A real creator on camera, reviewing or showing a specific product.

- Draft the full monologue first, then split it into beats.
- Write it as speech, in first person, with the small imperfections of someone talking.
- Split the monologue into segments of up to 15 seconds, each ending on a natural pause: 1 segment up to 15s, 2 up to 30s, 3 up to 45s, 4 up to 60s.
- Only say what the creator has really experienced. If that is unknown, ask rather than write a fake testimonial.
