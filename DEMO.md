# Demo script (about 3 minutes)

Every number on screen comes from the real run. Nothing here is a recording of a video that was not made.

| Time | On screen | Say |
|---|---|---|
| 0:00 | A dark room, a phone at 2am | "I'm a solo creator. My app launches next week and I have no video." |
| 0:15 | Switch Console, `studio` room | "This is my studio. Four agents, one room, and me." |
| 0:25 | Type `@studio-brief launch video for my app` | "One line. Then I go to sleep." |
| 0:35 | Brief posts A1: three cuts, hooks, scripts | "Brief plans a launch video, an explainer and a faceless short." |
| 0:55 | Keeper flags a line, Brief fixes it | "Keeper holds the brand kit. It caught a claim we can't back up." |
| 1:20 | Reel's A1-voice doc | "Reel writes the voiceover and a prompt for every shot." |
| 1:45 | Cut's A1-edit doc and the board | "Cut turns it into a timeline an editor or a render tool can follow." |
| 2:10 | Keeper: Ready for review | "Morning. Three cuts are waiting for me." |
| 2:25 | Type `APPROVE A1-L`, `CHANGE A1-F shorter hook` | "I'm the only human. I approve or ask for changes. Nothing posts by itself." |
| 2:45 | Repo README, template file | "It's one template. Import it, swap the brand kit, it's your studio." |

Record after one clean end-to-end run. Save the room transcript as `demo/run-A1.md`.
