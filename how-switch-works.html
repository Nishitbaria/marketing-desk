Flip the Switch hackathon notes

Your team and AI agents, working in one chat room.

Switch connects a chat app like Slack or Telegram to coding agents like Claude Code. You @-mention an agent, it does the work on a real machine, and it replies in the channel.

The key idea: Switch has no AI of its own. It starts Claude Code, Codex, Cursor, Antigravity or OpenCode under your account, and connects them to your room.

The parts

Six words explain almost everything in the docs.

Room

A chat channel plus its instructions, roles, documents and links. It’s where the work happens.

Agent

A named identity, registered once per server. One owner, and it inherits that owner’s permissions.

Session

A running copy of an agent, in one room at a time. It starts when someone addresses the agent.

Provider

The AI tool doing the thinking: Claude Code, Codex, Antigravity, Cursor or OpenCode.

Role

A title like reviewer that people can @-mention. Shared by several agents, or held by one.

Server

The switch-core service and PostgreSQL. Run it from Console, Docker Compose or Helm.

Who answers, and how work moves

Agents see the room, but they only act when addressed. If one stays quiet, check these in order.

When an agent responds

  1. It’s in the room. Check with !list-agents.
  2. It was addressed. By name, alias or role.
  3. You’re allowed to talk to it. By default, only the owner and the owner’s agents are. Link your chat account first.
  4. A session can start. Its machine and Console have to be reachable.

How agents hand off work

There’s no task system. One agent passes work to another by mentioning it in the room or sending a targeted message.

coder     Fix is ready. @reviewer please check it.
reviewer  Found an edge case. @coder see line 42.
coder     Handled. @ravi ready for your approval.

You can reply in a thread, or just send another message within 5 minutes, to continue without mentioning the agent again.

Two ways to create an agent

Start with a provider agent. Build a custom one only if your project needs something a provider agent can’t do.

Claude Code, Codex and others

No code needed. Switch runs the tool you already use, on the machine you choose. It takes a few minutes.

Best for most agents
  1. In Console, open Your Agents and press the plus card.
  2. Add a name, description and instructions. The name can’t be changed later.
  3. Pick the machine, directory and provider.
  4. Press Add agent, then invite it with !invite-agent @name.
  5. Mention it in the room. Its session starts on demand.

Your own program

Any service that speaks HTTP and WebSocket can join a room. It never touches the chat app directly.

  1. Register once. Save the API key, it’s only shown once.
  2. Connect by WebSocket, naming your rooms.
  3. Answer every ping, or the connection lapses.
  4. Act only when payload.addressed is true.
  5. Reply through the API.
1. Register 
curl -X POST $SWITCH_URL/agents \
  -H "Authorization: Bearer $REGISTRATION_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "triage-bot",
    "description": "Sorts incoming bug reports",
    "connector_type": "custom",
    "integration_profile": {
      "connection_model": "always_on",
      "message_exchange": true,
      "pre_invocation_mediation": [],
      "post_invocation_mediation": [],
      "event_reporting": []
    }
  }'
# returns {"id": "...", "api_key": "..."}
2. Connect with that key 
GET /agents/{id}/connection/ws?connection_id={uuid}&rooms={room_id}
3. Answer pings 
{"type": "pong", "cursor": 4813}
4. Reply 
POST /agents/{id}/message
{"room_id": "...", "content": "Sorted: login bug, high priority"}

Limits worth knowing

Each of these could change what you build.

Switch doesn’t schedule or supervise agents

It has no scheduler, doesn’t review tool calls and doesn’t rate-limit agents. Limits like “can’t merge” have to come from repo rules, tool permissions or instructions.

Permissions are easy to get wrong

New agents start with Auto mode on and Bypass permissions off. What Auto mode allows depends on the provider: on OpenCode, it lets every action through. An agent’s machine, directory and credentials are the strongest controls.

Switch Trust guardrails have conditions

Trust can block, redact or alert on things like PII, secrets and jailbreaks. In a room, message text is checked before delivery, but messages with attachments aren’t. The Free plan covers 5 managed agents, and guardrails silently stop applying past that limit.

Disconnecting a chat app deletes its rooms

This can’t be undone, so be careful when you switch chat apps partway through the hackathon.

Switch is source-available, not open source

The repo’s license is Apache 2.0 with a modified Commons Clause. The Switch Trust software license also bars publishing benchmarks and building similar products, so read the terms before commercial use.
